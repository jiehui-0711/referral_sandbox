# checks/

沙盒**外部**的東西。這個資料夾整個刪掉，沙盒照常執行
（`load` / `show` / `call` / `trace` / `run` 全部不受影響）。

公開程式時交出的版本不含這個資料夾。

```
checks/
  agent_visible.py   資料集檢查：Agent 看得到的字串
  tests/             程式行為的迴歸測試
  design/            設計階段的紀錄（誰都不讀，給人看的）
```

## agent_visible.py — 資料集檢查

把 Agent 在整個任務中看得到的字串全部收集起來，供逐項檢視。
資料集定稿後跑一次。

```bash
make dataset
```

## tests/ — 程式行為的迴歸測試

驗的是程式的行為，不是資料集的內容。改程式時跑。

```bash
make test
```

每一條守的都是「改壞了之後程式照跑、紀錄照印，但結果已經不對」的情況：

| 守什麼 | 破了會怎樣 |
|---|---|
| 每個案例拿到自己的病歷副本 | 上一題改過的電話留到下一題，90 組結果被汙染 |
| 工具不因臨床理由拒絕 | 環境開始代替 Agent 糾正 |
| 指引檢索只回五個欄位 | 中文設計筆記（含「本案例命中這一條」）流到 Agent |
| 沒有工具查得到用藥原因分類 | 最難的推導步驟退化成查表 |
| 同一組的五個變體世界相同 | 對照組不成立 |
| 病人與醫師不主動提示 | Agent 被免費送一步 |
| 失敗理由是封閉的那一組 | 臨床判斷混進環境 |
| 工具關卡的宣告與實作一一對應 | 關卡靜靜失效 |

這些測試用第一組任務當樣本，不遍歷全部任務，所以資料集長到九十組也不用改。
